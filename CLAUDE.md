# qwen-chat

- Les `SYNC.md` før du gjør noe. Kjør `.\sync.ps1` før arbeid, og `.\sync.ps1 "melding"` etterpå.
- Kun kjøre-PC-en (ZeroTrust, har fila `.kjore-pc`) kjører `server.js`, Ollama og modellen. Aldri start dem på laptopen.
- Versjonen står kun i `version.json`; header, footer, CHANGELOG og docs-panel skal alltid matche (bolletesten sjekker).
